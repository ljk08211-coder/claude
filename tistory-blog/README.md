# 티스토리 자동 예약 발행 (Aside + FreeLLMAPI)

네이버 블로그 키트(오.AI.완 naver-blog-free)와 같은 구조예요. Aside가 티스토리 글쓰기 화면을 직접 조작하고, 원고는 FreeLLMAPI 무료 AI가 써요. 이 폴더의 `tistory-reserve`는 Aside 스킬이에요.

티스토리 공식 Open API는 2024년에 종료돼서 API 방식은 쓸 수 없어요. 그래서 화면을 조작하는 방식으로 만들었어요.

## 무엇을 하나요

- 블로그 주제(술집 창업·F&B 창업·지원금·위스키·칵테일·전통주·바텐더·조주기능사)별로 구글·네이버 자동완성에서 세부 키워드를 찾아 2주 캘린더를 만들어요.
- 매일 정해진 시각에 오늘 글 1편을 써요.
  - 다음 검색 상위 티스토리 글의 분량, 소제목, 사진 수, 키워드를 분석해 그 포맷에 맞춰 써요.
  - 문장은 새로 쓰고, 참고 글과 20자 이상 같은 문장은 자동으로 걸러요.
- 무료 사진(위키미디어 공용, Openverse의 상업 이용 가능 사진)을 찾아 넣고, 출처를 사진 밑에 자동으로 표기해요.
- `settings.json`에 넣어 둔 쿠팡 파트너스 링크 중 글에 맞는 제품을 최대 2개까지 카드로 넣어요. 대가성 문구도 글 첫머리에 자동으로 붙여요.
- 태그와 카테고리를 넣고, **오늘 날짜로 예약 발행**해요.

## 설치

1. **네이버 키트를 먼저 끝내 두세요.** Aside, FreeLLMAPI, 무료 AI 연결을 함께 써요.
2. 이 폴더를 컴퓨터에 받으세요. GitHub 저장소 `ljk08211-coder/claude`에서 `claude/friendly-goodall-6wiblo` 브랜치를 고르고, **Code → Download ZIP**을 누른 뒤 압축을 푸세요.
3. Aside에서 **Settings → Plugins & MCPs → Skills → Import**를 누르고, `tistory-blog/tistory-reserve` **폴더 자체**를 고르세요. 폴더 안으로 들어가지 말고 폴더를 선택해야 해요.
4. Aside **New Chat**에 아래 요청문을 붙여 넣으세요.
5. 대화가 멈추는 곳에서만 직접 하면 돼요.
   - 카카오 로그인
   - 제휴 링크 입력
   - 카테고리 연결
   - 캘린더 승인
   - 루틴 모델을 "FreeLLMAPI Auto (무료)"로 변경

### Aside에 붙여 넣을 요청문

```text
tistory-reserve 스킬로 티스토리 정기 예약 발행을 설정해 줘. '6. 정기 발행 설정' 절차대로 진행해.

- 블로그: https://gwangtender.tistory.com
- 주제(pillars): 술집 창업, F&B 창업, 소상공인 지원금, 위스키, 칵테일, 전통주, 바텐더, 조주기능사
- 한 주 편수: 3편 (월·수·금 19:00)
- 공개 범위: 처음엔 비공개(private). 몇 편 확인한 뒤 내가 공개로 바꾸라고 할게.
- 루틴 실행: 매일 10:40
- 제휴 제품: 내가 줄 쿠팡 파트너스 링크만 써. 지금 없으면 제품 없이 시작해.
- 푸터 링크: 유튜브 '조선바텐더' 채널 주소는 내가 알려 줄게.

비밀번호·보안 퍼즐은 내가 직접 할 테니 그 단계에서는 멈추고 알려 줘.
```

먼저 한 편만 시험해 보려면 이렇게 보내세요.

```text
tistory-reserve 스킬로 "하이볼 만드는 법" 글을 하나 써서 오늘 저녁 9시에 비공개로 예약해 줘.
```

## 제휴 링크 넣는 법

1. 쿠팡 파트너스에서 상품 링크를 만드세요. 주소는 `https://link.coupang.com/a/...` 형태예요.
2. Aside 채팅에 이렇게 보내세요.

```text
티스토리 settings.json의 products에 추가해 줘.
- 이름: 스테인리스 바 스푼 30cm / 키워드: 칵테일, 홈텐딩, 하이볼 / 링크: https://link.coupang.com/a/xxxx / 설명: 긴 잔도 바닥까지 저어지는 길이
```

- 키워드가 글 주제와 겹치는 제품만 글에 들어가요. 한 글에 최대 2개예요.
- **술 자체는 링크하지 마세요.** 전통주를 빼면 주류 통신판매는 금지예요. 바 도구, 잔, 책, 시럽, 안주 같은 것만 넣으세요.

## 꼭 알아 둘 점

- **예약은 오늘 날짜로만 걸어요.** 그래서 루틴이 매일 돌아요. 실행 시각(기본 10:40)에 컴퓨터, Aside, FreeLLMAPI가 켜져 있어야 해요. 컴퓨터가 꺼져서 놓친 글은 다음 날 실행 때 이어서 처리해요. 이미 예약된 글은 컴퓨터가 꺼져 있어도 올라가요.
- **하루 1편만 써요.** 티스토리는 짧은 시간에 여러 번 발행하면 "틀린그림찾기" 보안 퍼즐을 띄워요. 스킬은 퍼즐을 풀지 않고 멈춰요. 우회는 계정 정지 사유예요.
- **루틴 설정에 쓴 채팅은 지우지 마세요.** 루틴이 그 채팅에 연결되어 있어요.
- **지원금·조주기능사 글의 숫자는 공식 출처로 확인해요.** 금액, 기간, 시험 일정 같은 숫자는 기업마당, 소상공인24, 큐넷 같은 공식 사이트에서 확인한 것만 써요. 확인이 안 되면 "공고에서 확인하세요"로 남겨요. 그래도 처음 몇 편은 직접 읽어 보고 공개하세요.
- **애드센스 승인 전이라면 품질이 우선이에요.** 하루 1편 이내, 비공개로 확인한 뒤 공개하는 흐름을 권장해요.
- **사진은 출처 표기가 붙어요.** 무료 사진은 출처 표기 조건(CC BY)이 있어서 사진 밑에 작가와 라이선스가 자동으로 붙어요. 지우지 마세요. 직접 찍은 사진이나 AI 사진을 쓰고 싶으면 그 글만 손으로 바꾸면 돼요.

## 첫 실행 때 막히면

티스토리 화면 구조 일부는 아직 실제 계정에서 확인하지 못했어요. 다른 날짜 달력과 예약 글 목록이 그래요. 화면이 바뀌어 막히면 스킬이 화면 구조를 덤프(`TS.probe`)하고 멈춰요. 그 결과를 복사해서 Claude에게 보내 주면 셀렉터를 고쳐 드릴게요.

| 오류 | 뜻 |
|---|---|
| `LOGIN_REQUIRED` | 카카오 로그인이 풀렸어요. Aside에서 다시 로그인하세요 |
| `EDITOR_NOT_FOUND` / `BODY_FAILED` | 글쓰기 화면 구조가 바뀌었어요. probe 결과를 보내 주세요 |
| `DATE_UI` / `TIME_UI` / `RESERVE_UI` | 예약 칸을 못 찾았어요. 즉시 발행하지 않고 멈춘 거예요 |
| `NOT_CONFIRMED` | 제목, 시각, 공개 범위 중 하나가 달라서 버튼을 누르지 않았어요 |
| `captcha: true` | 보안 퍼즐이 떴어요. Aside 화면에서 직접 풀거나 다음 날 다시 해요 |

## 파일

```
tistory-reserve/
  SKILL.md                 Aside가 따르는 절차서
  scripts/tistory-editor.js 티스토리 에디터 조작 도우미 (TS.*)
  settings.example.json    설정 예시 (블로그·주제·제휴 제품·푸터)
```

실행 중 만들어지는 파일은 Aside 계정 폴더의 `tistory-autopilot/` 아래에 생겨요.
- `settings.json`: 블로그, 제휴 제품 등 설정
- `calendar.json`: 발행 캘린더

에디터 셀렉터는 2026년 7~8월 실제 계정에서 검증된 공개 자동화 코드([yoo9857/mytis](https://github.com/yoo9857/mytis))를 참고했어요.
