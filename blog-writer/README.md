# 블로그 글 품질 개선 (blog-writer)

네이버와 티스토리 자동 발행 모두에 쓰는 **공통 글쓰기 엔진**이에요. 예약은 기존 스킬(naver-blog-reserve, tistory-reserve)이 그대로 하고, 그 앞의 조사와 원고 단계만 이 스킬로 바뀌어요.

## 왜 바꿨나: 벤치마크 결과 요약

우리 주제 키워드 24개로 네이버 상위 글 127개와 티스토리 상위 글 29개를 실제로 분석했어요. 자세한 내용은 `references/benchmark-2026-10.md`에 있어요.

- **줄이 짧아요.** 상위 글은 한 줄(문단)이 평균 19자예요. 문장을 2~3줄로 끊고 1~3줄마다 빈 줄을 넣어요. 무료 AI 원고는 한 문단에 3~5문장을 몰아넣어 모바일에서 벽처럼 보였어요.
- **반응 좋은 글은 짧고 말을 걸어요.** 공감 상위 1/3 글은 반응 낮은 글보다 짧았고(약 1,550자 대 2,300자), 사진이 많았어요(7.5장 대 3장). 말투도 "~해요"였어요. 반응 낮은 글은 "~합니다" 비중이 42%였어요.
- **이 분야 상위에는 진짜 전문가가 거의 없어요.** 반복 노출되는 계정은 대부분 종합 블로그예요. 주 156편을 찍어 내는 대량 생산 계정은 공감이 0이었어요. 현직 바텐더이자 바 사장의 경험이 가장 큰 무기예요.

## 무엇이 달라지나

| 전 | 후 |
|---|---|
| AI가 한 번에 긴 원고를 쓰고 그대로 입력 | 유형별 목차(레시피, 추천, 입문, 지원금, 시험, 창업)를 잡고 섹션 하나씩 작성 |
| 문단 나누기를 AI에 맡김 | **자동 문단 정리**: 네이버는 약 22자 줄과 빈 줄, 티스토리는 1~2문장 문단 |
| 검사는 분량과 키워드만 | **품질 검사 추가**: AI 말투(결론적으로, 다양한, 알아보겠습니다 등 30여 개), 말투 섞임, 같은 어미 반복, 60자 넘는 문장, 첫 3문장 훅, 경험 문장 2개 이상, 유형별 구체 숫자 |
| 경험 없이 일반론 | **지식 노트**: 사장님이 적어 둔 실제 경험·레시피·숫자를 글에 1인칭으로 넣음 |
| 기준 숫자가 고정 | **벤치마크 갱신**: `W.bench`로 한 달에 한 번 상위 글을 다시 재서 기준을 바꿈 |

같은 원고를 정리하면 이렇게 바뀌어요(네이버).

```
저희 바결에서는 위스키 45ml에 탄산수
135ml를 기본으로 써요.

얼음은 잔 끝까지 꽉 채우고, 위스키를 먼저 넣은
다음 바스푼으로 열 번 정도 저어서 잔을
차갑게 만들어요.
```

## 설치

1. GitHub `ljk08211-coder/claude` 저장소의 `claude/friendly-goodall-6wiblo` 브랜치를 **Code → Download ZIP**으로 받아 압축을 푸세요.
2. Aside에서 **Settings → Plugins & MCPs → Skills → Import**를 누르고 `blog-writer` 폴더를 고르세요. 티스토리를 쓰면 `tistory-blog/tistory-reserve`도 새 버전으로 다시 Import하세요(기존 것은 지우고).
3. Aside 새 채팅에 이렇게 보내세요. 기존 루틴이 새 절차로 글을 쓰게 바뀌어요.

```text
blog-writer 스킬의 '9. 처음 설치 후 한 번' 절차대로 네이버·티스토리 정기 루틴의 prompt를 바꿔 줘.
```

4. **지식 노트를 채우세요.** 효과가 가장 커요. Aside 계정 폴더의 `blog-knowledge/knowledge.md`에 생겨요. 채팅으로 이렇게 말해도 돼요.

```text
지식 노트에 추가해 줘: 하이볼 비율 - 바결은 위스키 45ml에 탄산 135ml, 얼음은 잔 끝까지, 위스키 넣고 10번 저어 칠링한 뒤 탄산은 잔 벽으로. 손님들이 집에서 제일 많이 틀리는 건 얼음을 적게 넣는 것.
```

## 원고 모델 올리기 (권장)

글 품질의 절반은 모델이에요. 지금 FreeLLMAPI의 `auto`는 Kilo와 OVH의 작은 무료 모델로 돌아가서 한국어 글이 약해요. 무료로 바로 올릴 수 있어요.

1. **Google AI Studio에서 무료 키를 받으세요.** aistudio.google.com/apikey 에서 받으면 돼요. 유튜브 정리 스킬에 쓰는 GEMINI 키가 있다면 그걸 써도 돼요.
2. **FreeLLMAPI 대시보드의 Keys에서 Add key → Google을 고르고 키를 붙여 넣으세요.** 키는 채팅에 붙여 넣지 말고 대시보드에만 넣으세요.
3. **Aside 모델 목록에 똑똑한 모델을 추가하세요.** Aside **Settings → Models**에서 FreeLLMAPI 항목을 편집하고 models에 아래 한 줄을 더하세요. FreeLLMAPI의 `auto:smart`는 품질 우선으로 모델을 골라요.

```json
{ "id": "auto:smart", "name": "FreeLLMAPI Smart (무료)", "reasoning": false, "input": ["text"], "contextWindow": 128000, "maxTokens": 16384 }
```

4. **루틴 모델을 바꾸세요.** 루틴 카드에서 Edit → Model → **FreeLLMAPI Smart (무료)** → Update를 누르세요.

## 손으로 하면 효과가 큰 것 (자동화 안 됨)

- **가운데 정렬(네이버):** 반응 좋은 글의 38%가 가운데 정렬이었어요. 예약된 글을 열어 본문 전체 선택 → 가운데 정렬만 해도 돼요.
- **바결 현장 사진:** 무료 사진 1장을 직접 찍은 사진 1장으로만 바꿔도 신뢰가 크게 달라져요.
