# 릴스편집팀 — 클로드로 캡컷 없이 릴스 완성본까지

말로 찍은 세로 영상 하나를 넣고 "편집해줘" 라고 하면, Claude Code 가 완성 mp4 를 만들어 줍니다.
맥과 윈도우에서 쓸 수 있어요. 설치는 맥이면 [INSTALL.md](INSTALL.md), 윈도우면 [INSTALL_WINDOWS.md](INSTALL_WINDOWS.md) 의 문장을 Claude Code 에 붙여넣으면 끝나요.

## 되는 것

**1. 기본 편집 — `reels-edit-lite`**
- 무음 컷: 0.3초 넘는 공백을 잘라 이어 붙임
- 한국어 자막: 짧은 줄(11자 안팎), 흰 글자 + 검은 박스
- 효과음: 문장 시작에 pop·click, 장면이 바뀌는 곳에 whoosh
- 장면 전환: 문장이 바뀌는 컷에 살짝 줌인 (검은 화면 없음)
- 출력: 1080x1920 mp4. 가로 영상을 넣으면 가운데를 잘라 세로로

**2. 위아래 분할 — 위는 화면 자료, 아래는 얼굴**
- 위 칸에 화면 녹화·이미지·카드 영상 아무거나
- 자막은 두 칸 경계 가운데

**3. 도트 카드 — `grid-dot-cards`**
- 모눈종이 배경 + 파스텔 오로라 + 도트 글씨(한글) 카드
- 문장마다 카드가 바뀌고, 제목은 클로드가 문장을 요약해서 넣음
- 위 절반용(1080x960) / 풀 화면용(1080x1920)

## 이렇게 말하면 됩니다

폴더에서 `claude` 를 켠 뒤:

| 말 | 결과 |
|---|---|
| `편집해줘 input/얼굴.mp4` | 무음 컷 + 자막 + 효과음 + 줌 완성본 |
| `위에 카드 넣어서 편집해줘 input/얼굴.mp4` | 위 = 문장마다 바뀌는 도트 카드, 아래 = 얼굴. 카드 문구는 만들기 전에 표로 보여줌 |
| `위에 이 화면 녹화 넣어서 편집해줘 input/얼굴.mp4 input/녹화.mp4` | 위 = 화면 녹화, 아래 = 얼굴 |
| `자막에 '기텁' 을 '깃헙' 으로 고쳐서 다시 해줘` | 자막수정.txt 에 적고 다시 만듦 (이전 결과는 _v2 로 따로 저장) |
| `효과음 빼줘` / `줌 빼줘` | 해당 기능만 끄고 다시 |
| `얼굴 머리가 잘려` | 아래 칸 얼굴 위치를 내려서 다시 |
| `이 내용으로 도트 카드 영상 만들어줘` | 카드 영상만 (풀 화면 또는 위 절반) |

결과는 `out/` 폴더에 생기고, 끝나면 폴더가 열립니다.

## 폴더 구성

```
릴스편집팀/
├─ README.md, INSTALL.md
├─ input/                ← 여기에 영상 넣기
├─ out/                  ← 결과물
├─ bin/, models/, sfx/   ← 설치할 때 자동으로 받음 (ffmpeg, 자막 모델, 효과음)
└─ .claude/              ← 숨김 폴더: 스킬 2개 + 실행 허용 설정
   ├─ settings.json
   └─ skills/
      ├─ reels-edit-lite/   (SKILL.md, scripts/edit.py)
      └─ grid-dot-cards/    (SKILL.md, assets/template.html, assets/fonts/, scripts/render.mjs)
```

## 알아두면 좋은 것

- 시간(예상): 1분 영상 기준 기본 편집은 1분 안팎, 도트 카드는 렌더에 약 4분이 더 걸립니다.
- 자막 정확도: 영어 고유명사(서비스 이름 등)가 잘 틀립니다. 끝나면 클로드가 오타 후보를 보여줘요.
- 얼굴 칸: 분할 화면에서는 얼굴 영상의 가운데 부분을 잘라 씁니다. 머리나 턱이 잘리면 말로 고쳐 달라고 하세요.
- 화면 녹화: 위 칸 비율이 9:8 이라 브라우저 창을 정사각형에 가깝게 줄이고 녹화하면 글씨가 크게 보입니다.
