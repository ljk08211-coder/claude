# 경매 적정 입찰가 추천 시스템 — 기획서

> 목표: 사건번호(또는 관심 물건) 하나를 넣으면 **시세 추정 → 권리·비용 계산 → 낙찰 확률 예측 → 입찰가 3안 추천**까지 자동으로 나오는 워크플로우.
> 사람이 하는 일은 **현장조사 체크리스트 입력**과 **최종 판단** 두 가지로 줄이는 것이 목표다.

---

## 1. 핵심 아이디어: 입찰가는 "두 개의 숫자" 사이에서 고른다

```
   최저매각가격 ─────────── [ 추천 입찰가 ] ─────────── 수익 상한가
   (법원이 정한 하한)        (기대수익이 최대인 지점)      (이 이상 쓰면 목표수익 미달)
```

| 숫자 | 뜻 | 계산 방법 |
|---|---|---|
| **수익 상한가** (Max Bid) | 이 가격을 넘으면 목표 수익을 못 낸다 | 시세 − 수리비 − 명도비 − 인수금액 − 세금·비용 − 목표이익을 **역산** |
| **낙찰 확률 곡선** | 이 가격을 쓰면 낙찰될 확률 | 비슷한 물건들의 과거 낙찰가/시세 비율 분포 |
| **추천 입찰가** | 위 둘을 합쳐 기대수익(=낙찰확률 × 이익)이 가장 큰 가격 | 최저가 ~ 상한가 구간을 훑어서 최댓값 |

- 최저가 > 상한가 → **자동으로 "입찰 비추천(패스)"** 판정.
- 추천 가격이 낙찰확률이 너무 낮으면 → **"이번 회차 패스, 다음 회차(유찰 시 최저가 ○억) 노리기"** 시나리오도 같이 보여준다.

> 감정가는 기준으로 쓰지 않는다. 감정평가는 입찰일보다 6개월~1년 전에 이뤄져서 시장과 어긋나는 경우가 많다. 모든 비율은 **현재 시세 기준**으로 계산한다.

## 2. 전체 워크플로우 (자동화 범위 표시)

```
[0] 관심조건 설정 ─ 지역 / 유형(아파트 등) / 가격대 / 투자전략            (1회 설정)
        │
[1] 물건 수집 ──── 사건번호 입력 or 매일 신건·유찰 목록 수집               🤖 자동 (2단계부터)
        │
[2] 서류 해석 ──── 감정평가서·매각물건명세서·현황조사서 PDF → AI가 추출     🤖 자동
        │           (면적, 층, 점유자, 임차인, 특별매각조건, 위험 키워드)
        │
[3] 데이터 보강 ── 실거래가 / 시세지수 / 건축물대장 / 공시가격 API          🤖 자동
        │
[4] 1차 스크리닝 ─ 위험물건 자동 탈락 + 대략 상한가 계산 → 점수순 정렬     🤖 자동
        │           → "현장 가볼 만한 물건"만 알림
        │
[5] 현장조사 ──── 모바일 체크리스트 (컨디션, 점유자, 관리비 체납, 호가)    🙋 사람
        │
[6] 가격 엔진 ─── 시세 확정 → 비용 계산 → 상한가 → 낙찰확률 → 추천 3안     🤖 자동
        │
[7] 리포트 ────── HTML/엑셀 리포트 + 알림(텔레그램/카톡)                   🤖 자동
        │
[8] 결과 기록 ─── 실제 낙찰가·입찰자 수 저장 → 낙찰확률 모델이 점점 정확해짐 🤖 자동
```

| 감정평가서·매각물건명세서·현황조사서 | 법원경매정보 PDF | PDF 업로드 → AI 추출 | 무료 + AI 비용 소액 | 1 |
| 등기부등본 | 인터넷등기소 | 1단계: PDF 업로드 · 이후: 유료 연동 API 검토 | 건당 수백 원 | 2 |
| 과거 낙찰 결과 (낙찰가, 입찰자 수) | 법원경매정보 매각결과 + 직접 기록 | 누적 DB | 무료 | 2 |
| KB시세 / 네이버 호가 | 공식 API 없음 | **수동 입력** (현장조사 때 같이) | 무료 | 1 |

> ⚠️ 법원경매정보·네이버부동산은 공식 API가 없고 자동 수집을 막아둔 부분이 있다. 1단계는 **수동 입력 + PDF 업로드**로 시작하고, 자동 수집은 이용약관을 확인한 뒤 하루 1회 소량으로만 한다. 탱크옥션·지지옥션 같은 유료 사이트를 쓰고 있다면 거기서 받은 정보를 붙여넣는 방식도 지원한다.

## 4. 가격 엔진 상세 로직

### 4-1. 시세 추정 (Market Value)

아파트 기준. 아래 순서로 **비교 사례**를 모으고 가중 중앙값을 낸다.

1. **같은 단지·같은 평형** 최근 6개월 실거래 (3건 이상이면 이것만으로 충분)
2. 부족하면 **같은 단지 유사 평형** (전용 ±10%) → ㎡당 단가 × 대상 면적
3. 그래도 부족하면 **인근 유사 단지** (반경 500m, 연식 ±5년, 세대수 비슷) → ㎡당 단가, 거리·연식 차이만큼 가중치 낮춤

각 사례에 보정을 건다.

| 보정 | 방법 (기본값, 설정에서 변경 가능) |
|---|---|
| 시점 보정 | 거래 시점 → 오늘까지 R-ONE 지역 매매지수 변동률만큼 |
| 층 보정 | 1층 −7%, 2층 −4%, 탑층 −2%, 그 외 0% |
| 이상거래 제거 | 직거래·특수관계 의심(중앙값 대비 ±15% 밖) 제외 |

**교차검증**: KB시세(일반가)와 현장 호가(최저 호가 3곳)를 입력하면 같이 비교한다.
세 값의 차이가 10% 넘게 벌어지면 **"시세 신뢰도 낮음"** 경고 → 보수적으로 가장 낮은 값을 쓴다.

출력: `시세 = 4억 9,800만 (신뢰도: 높음, 비교사례 7건)`

### 4-2. 비용 계산

| 항목 | 계산 |
|---|---|
| 취득세 (+지방교육세·농특세) | 낙찰가 × 세율. 주택 수·조정대상지역·가격구간·면적별 세율표(설정 파일) |
| 법무비·등기비 | 낙찰가 × 약 0.3~0.5% (설정) |
| 명도비 | 점유자 유형별: 소유자/채무자 → 이사비 기본값, 배당받는 임차인 → 낮음, 배당 못 받는 임차인 → 높음 |
| 수리비 | 현장조사 컨디션 등급 × 평당 단가표 (도배·장판 / 욕실 / 주방 / 섀시 / 전체 리모델링) |
| 체납 관리비 | 공용부분만 인수 (입력값 × 공용비율, 기본 약 60%) |
| 인수 금액 | 권리분석 결과 (4-3) |
| 보유비용 | 대출이자 × 예상 보유기간 + 재산세 등 |
| 매도비용 (매도 전략일 때) | 중개보수 + 양도소득세 (보유기간별 세율) |

> 세율·대출 규제는 자주 바뀐다. 전부 `config.yaml`에서 관리하고, 리포트에 "적용 세율표 기준일"을 같이 찍는다.

### 4-3. 권리분석 자동 플래그

등기부·매각물건명세서에서 추출한 권리/임차인 목록으로 규칙 기반 판정을 한다.

1. **말소기준권리** 찾기: (근)저당·압류·가압류·담보가등기·경매개시결정 중 가장 빠른 것
2. 말소기준보다 **앞선 권리** → 인수 (금액 있으면 비용에 더함)
3. **임차인 대항력**: 전입일 다음날 0시가 말소기준일보다 빠르면 대항력 있음
   - 대항력 + 배당요구 + 확정일자 → 배당 순위 시뮬레이션, 못 받는 금액만 인수
   - 대항력 + 배당요구 안 함 → 보증금 **전액 인수**
4. **자동 탈락(레드 플래그)** — 초보 단계에선 무조건 패스
   - 유치권 신고, 법정지상권, 지분경매, 대지권 미등기, 토지별도등기, 선순위 가처분·가등기, 위반건축물, 특별매각조건(재매각 보증금 20% 등)
5. **주의(옐로 플래그)** — 리포트에 표시만
   - 전입세대 열람 필요, 관리비 체납 큼, 현황조사서상 "폐문부재"

> 권리분석은 "의심 신호를 놓치지 않는 것"이 목적이다. 엔진이 애매하다고 판단하면 **"전문가 확인 필요"**로 표시하고 상한가를 보수적으로 계산한다.

### 4-4. 수익 상한가 역산

투자 전략별로 다르게 계산한다.

**A. 보유·실거주형** — "총 취득원가가 시세의 X% 이하"
```
낙찰가 × (1 + 취득세율 + 법무비율) + 수리비 + 명도비 + 관리비 + 인수금액 ≤ 시세 × 목표비율
→ 상한가 = (시세 × 목표비율 − 고정비용 합계) ÷ (1 + 취득세율 + 법무비율)
```

**B. 매도차익형** — "보유기간 후 매도해서 세후 순이익 Y원 이상"
```
(매도가 − 매도비용 − 양도세(낙찰가) − 보유비용) − (낙찰가 × (1+부대비율) + 고정비용) ≥ 목표이익
→ 양도세가 낙찰가에 따라 달라지므로 이분탐색으로 계산
```
> 주택은 단기 양도세율이 매우 높아(1년 미만·2년 미만 구간) B 전략은 보유기간 설정이 결정적이다.

**C. 임대수익형** — "실투자금 대비 연 수익률 Z% 이상" (월세/전세 실거래 API 활용)

### 4-5. 낙찰 확률 예측

**1단계 (규칙 기반, 데이터 적어도 동작)**
- 같은 지역(시·군·구) + 같은 유형 + 최근 3~6개월 낙찰 사례의 **낙찰가 ÷ 시세** 비율 분포를 만든다.
- 입찰가 b의 낙찰 확률 ≈ 그 분포에서 b/시세 보다 낮은 사례 비율 (누적분포).
- 보정: 유찰 횟수, 소형 평형(인기 높음), 대단지, 역세권이면 분포를 오른쪽으로 이동.

**2단계 (데이터 쌓이면)**
- 누적된 낙찰 결과로 머신러닝 모델(Gradient Boosting) 학습 → 낙찰가율·입찰자 수 예측.
- 매 경매 결과가 들어올 때마다 자동 재학습.

### 4-6. 최종 추천

```
for b in 최저가 ~ 상한가 (100만 원 단위):
    기대수익(b) = 낙찰확률(b) × 이익(b)
추천 = 기대수익이 최대인 b
```

리포트에는 3안을 같이 보여준다.

| 안 | 기준 | 용도 |
|---|---|---|
| 🟢 보수 | 낙찰확률 약 30% 지점 | 이익 최대, 떨어져도 괜찮을 때 |
| 🟡 추천 | 기대수익 최대 지점 | 기본값 |
| 🔴 공격 | 상한가 바로 아래 | 꼭 잡고 싶을 때 (그래도 상한가는 절대 안 넘김) |

- 끝자리는 경쟁자들이 많이 쓰는 딱 떨어지는 금액을 피해 **홀수 끝자리**로 맞춘다 (예: 4억 2,300만 → 4억 2,317만 원).
- 입찰보증금(최저가의 10%, 재매각은 20%)도 같이 표시한다.

## 5. 예시 (숫자로 보는 흐름)

> 서울 ○○구 ○○아파트 84㎡, 감정가 5억 2,000만, 1회 유찰 → 최저가 4억 1,600만
> 전략 A(보유형), 목표: 총 취득원가 ≤ 시세의 90%, 1주택자

| 단계 | 결과 |
|---|---|
| 시세 추정 | 같은 단지 84㎡ 실거래 5건, 시점·층 보정 → **5억** (신뢰도 높음) |
| 권리분석 | 말소기준 2023 근저당, 임차인 없음(소유자 점유) → 인수 0원, 레드플래그 없음 |
| 비용 | 수리비 1,500만 + 명도비 300만 + 공용관리비 200만 = 2,000만 / 부대비율 1.6% (취득세 1.1% + 법무 0.5%) |
| 상한가 | (5억 × 90% − 2,000만) ÷ 1.016 = **약 4억 2,300만** |
| 낙찰확률 | 구 내 최근 낙찰가/시세: 하위25% 84% · 중앙 88% · 상위25% 92% → 4억 2,300만(시세의 84.6%)이면 **약 28%** |
| 판정 | 🟡 추천 4억 2,317만 (확률 28%) · "다음 회차 대기" 시나리오: 유찰 확률 낮음(인기 평형) → 이번 회차 입찰 권장 |

## 6. 사람이 하는 일: 현장조사 체크리스트 (모바일 입력)

체크박스·숫자 입력만으로 끝나게 만든다. 입력하면 수리비·명도비가 자동 계산된다.

- **외관/공용**: 누수 흔적, 외벽 균열, 주차 여건
- **세대 컨디션** (등급 상·중·하): 섀시 / 욕실 / 주방 / 도배·바닥 / 보일러 (내부 못 보면 관리사무소·이웃 정보로 추정)
- **점유자**: 거주 여부, 우편물 이름, 관리사무소 확인 사항
- **관리비 체납액**: 관리사무소 문의
- **호가**: 중개사무소 3곳 최저 호가, 급매가, 체감 분위기
- **사진 업로드** (선택) → AI가 컨디션 등급 보조 판정 (3단계)

## 8. 단계별 로드맵

| 단계 | 기간(예상) | 범위 | 완료 기준 |

## 9. 리스크와 원칙

1. **상한가는 절대 넘기지 않는다.** 엔진이 추천하는 모든 가격은 상한가 이하.
2. **모르면 보수적으로.** 시세 신뢰도 낮음·권리 애매 → 낮은 값으로 계산하고 경고.
3. **최종 판단은 사람.** 권리관계가 복잡한 물건은 법무사·전문가 확인 후 입찰. 이 시스템은 투자·법률 자문이 아니라 판단 보조 도구다.
4. **입찰표 실수 방지 체크**: 금액 자릿수, 사건번호·물건번호, 보증금액을 리포트 마지막에 한 번 더 표시.
5. **수집 예절**: 공식 API 우선, 공식 API 없는 사이트는 약관 확인 후 소량만.

### 실데이터 검증 (2026-10-14, 부산 해운대구)

국토부 API로 최근 12개월 매매 4,038건·전월세 7,258건 수집. 2026년 8~10월 실거래 398건을 **그 이전 데이터만으로** 추정해 실제 가격과 비교했다.

| 항목 | 결과 |
|---|---|
| 중앙 오차 | **4.3%** (처음 5.3% → 4.9% → 4.3%) |
| ±10% 안에 든 비율 | 약 77% |
| 1~3억 구간 | 중앙 오차 4.8% |
| 참고: 같은 달·같은 단지·같은 평형끼리의 자연 편차 | 2.4% |

검증하며 고친 것: 부분 일치로 다른 단지가 섞이던 문제(현대 ↔ 현대카멜리아) → 단지 고유번호·정확한 이름 우선 매칭 / 층 보정을 실측치로 교체(1층 −11%, 2층 −5.5%, 3~5층 −2%) / 최근 거래 가중 강화 / 비교사례 2건이 서로 멀 때 멈추던 버그 / 신고기한(30일)이 안 지난 최근 두 달을 지수에 넣어 가짜 하락으로 시세를 낮추던 버그(가장 큰 개선).

### 지수 개선 (부산진구 검증)

2025타경21826 분석 중, ㎡당 중앙값 지수가 "그 달 어떤 단지가 팔렸나"에 따라 ±12% 출렁이는 것을 발견(같은 단지 가격은 ±1%). 같은 단지·같은 평형끼리 비교하는 지수로 교체.

| 백테스트 | 기존 | 개선 |

| 부산진구 1~3억 중앙 오차 | 8.2% | 6.9% |

### 첫 실제 사건 (2025타경5349, 해운대 일동미라주 57㎡, 3회차)

- 실제 사건에 돌려보니 낙찰확률 모델이 깊게 유찰된 물건에서 엉뚱한 답(최저가 낙찰확률 3%)을 냈다 → **유찰 물건은 직전 회차 최저가를 기준으로** 낙찰가 분포를 잡도록 바꿨다 (임시 가정, 낙찰결과가 쌓이면 실제 분포로 대체).
- 부산지법 동부지원은 저감률 30% → 사건별 `reduction_rate` 로 반영.

남은 오차는 동·라인·조망·내부 상태처럼 실거래 자료에 없는 정보에서 온다 → 현장조사 호가·KB 교차검증으로 보완.

다음(2단계): 다른 구(부산진구·사하구·북구 등)로 시세 검증 확대 → 부산 낙찰사례 누적 → 매일 신건 스크리닝·알림 → 웹 대시보드.
