# 유튜브 자막 + 장면 정리

유튜브 링크 하나로 다음 세 가지를 만든다.

1. **자막 파일**: 원본 `.srt` 파일과, 타임스탬프가 붙은 읽기용 `transcript.txt`
2. **장면 목록**: 장면 전환마다 캡처한 이미지와 시간, 그 구간 자막을 담은 `scenes.md`
3. **핵심 요약 5줄**: `summary.md`

## 1단계: 프로그램 확인 (설치는 반드시 먼저 물어본다)

```bash
python3 <이 스킬 폴더>/scripts/youtube_digest.py check
```

- `OK` → 2단계로.
- `MISSING: ...` → **절대 바로 설치하지 않는다.** 출력된 프로그램 이름과 설치 명령을 사용자에게 보여주고, 설치해도 되는지 물어본다(AskUserQuestion이 있으면 사용). 사용자가 허락한 것만 설치하고 `check`를 다시 실행한다. 거절하면 무엇이 없어서 못 하는지 알려주고 멈춘다.
- `python3` 자체가 없으면(Windows는 `python`이나 `py`로 시도) 그것도 똑같이 먼저 물어본다.
- 그 밖에 이 과정에서 무엇이든 새로 설치해야 하면(예: deno, 브라우저 쿠키 도구) 같은 규칙을 따른다.

## 2단계: 실행

```bash
python3 <이 스킬 폴더>/scripts/youtube_digest.py run "<유튜브URL>" --out youtube-digest
```

결과는 `youtube-digest/<영상ID>/`에 저장된다.

| 파일 | 내용 |
|---|---|
| `subtitles.<언어>.srt` | 원본 자막. 수동 자막을 먼저 받고, 없으면 자동 자막을 받는다 |
| `transcript.txt` | `[00:01:23] 문장` 형식의 읽기용 자막 |
| `scenes/scene_001_00-00-00.jpg` … | 장면 캡처(가로 640px) |
| `scenes.md` / `scenes.json` | 장면 번호, 시간(해당 위치로 가는 유튜브 링크), 캡처, 그 구간 자막 |
| `meta.json` | 제목, 채널, 길이, 설명, 자막 상태, 장면 감지 방식 |

옵션:
- `--threshold 0.3`: 장면 전환 민감도. 장면이 너무 많으면 0.4~0.5로 올리고, 너무 적으면 0.2로 내린다.
- `--min-gap 2`: 장면 사이 최소 간격(초). 쇼츠처럼 컷이 빠르면 1로 낮춘다.
- `--max-scenes 40`: 장면 최대 개수. 넘으면 고르게 골라 남긴다.
- `--keep-video`: 장면 감지용으로 받은 저화질 영상을 지우지 않고 남긴다(기본은 삭제).
- `--cookies-from-browser chrome`: 연령 제한이나 로그인이 필요한 영상일 때 쓴다.

장면 전환이 3개도 안 잡히는 영상(고정 화면, 팟캐스트 등)은 자동으로 일정 간격 캡처 10장으로 바꾼다. 이때 `meta.json`의 `scenes.method`가 `interval`이 된다.

## 3단계: 자막이 없을 때

콘솔에 `NO_SUBTITLES`가 나오거나 `meta.json`의 `subtitle.status`가 `"none"`이면 **사용자에게 분명히 알린다**:

> 이 영상에는 내려받을 수 있는 자막(수동/자동 모두)이 없어요. 장면 캡처와 영상 설명만으로 정리했어요.

이 경우에도 장면 캡처는 그대로 만들고, 요약은 캡처 이미지와 제목, 설명을 바탕으로 쓴다. 요약 맨 위에 "자막 없음, 화면 기준 요약"이라고 표시한다. 음성 인식(Whisper 등)으로 자막을 만들 수 있다는 것은 알려줄 수 있지만, 설치가 필요하므로 사용자가 원할 때만 하고 설치 전에 반드시 물어본다.

자동 자막(`subtitle.status: "auto"`)이면 인식 오류가 있을 수 있다고 한 줄 알려준다.

## 4단계: 장면 설명 채우기

`scenes.md` 표의 마지막 칸 **장면 설명**은 비어 있다. 캡처 이미지를 직접 보고 칸을 채운다.

- 장면이 15개 이하이면 모두 본다.
- 그보다 많으면 자막 내용이 바뀌는 지점과 처음, 끝 장면을 우선으로 15개 안팎만 보고, 나머지는 자막을 근거로 짧게 쓴다.
- 설명은 한 줄로 쓴다. 화면에 보이는 것(인물, 제품, 자막 텍스트, 장소)을 적는다. 예: "바 카운터에서 셰이커를 흔드는 클로즈업, 화면 자막 '이것만 알면 끝'".

## 5단계: 핵심 요약 5줄

`transcript.txt`(없으면 장면과 설명)를 읽고 `summary.md`에 쓴다.

```markdown
# <영상 제목>
<채널> · <길이> · <링크>

## 핵심 요약
1. …
2. …
3. …
4. …
5. …
```

- 정확히 5줄로 쓴다. 한 줄에 한 문장, 영상 흐름 순서대로 쓴다.
- 영상이 실제로 말하는 내용만 쓰고, 추측은 넣지 않는다.
- 중요한 줄에는 근거가 되는 시간을 `(03:12)`처럼 붙인다.

## 6단계: 사용자에게 보고

채팅에는 길게 쓰지 않는다. 다음만 알려준다.

- 결과 폴더 경로
- 자막 상태(수동/자동/없음, 언어)
- 장면 개수
- 핵심 요약 5줄을 그대로 붙여 넣기

## 문제 해결

- **`영상 정보를 가져오지 못함`**: 먼저 yt-dlp 업데이트를 제안한다(설치와 같으니 먼저 묻는다). 비공개, 연령 제한, 지역 제한 영상이면 `--cookies-from-browser`를 안내한다.
- **`VIDEO_DOWNLOAD_FAILED`**: 최신 yt-dlp는 유튜브 영상을 받을 때 JavaScript 런타임(deno)을 필요로 할 수 있다. 오류 메시지에 그런 내용이 있으면 deno 설치를 제안하되 먼저 묻는다. 자막과 요약은 그대로 전달한다.
- **장면이 너무 많거나 적음**: `--threshold`, `--min-gap` 값을 조절해 다시 실행한다.
