# 상세페이지 디렉션 가이드

SKILL.md의 각 단계에서 필요한 부분만 찾아 읽는다.

## A. 벤치마킹 분석표

경쟁 상세페이지 하나마다 아래 표를 채운다. 화면에 실제로 보이는 것만 쓰고, 추측은 "추정"이라고 적는다.

| 항목 | 기록할 것 |
|---|---|
| 상품 | 플랫폼(쿠팡/네이버), 상품명, 판매가, 리뷰 수/평점, 로켓 여부, 링크 |
| 첫 화면 | 헤드카피 원문, 배경(연출컷/누끼/모델), 배지 문구 |
| 섹션 순서 | `히어로 → 공감 → 포인트3 → …`처럼 흐름 그대로 |
| 핵심 셀링포인트 | 3~5개. 각각 어떤 근거(수치·실험·인증·비교)로 보여주는지 |
| 카피 톤 | 반말/존댓말, 문장 길이, 감성형/정보형 |
| 시각 스타일 | 주조색, 폰트 굵기, 배경 밝기, 사진 비율(연출:누끼:텍스트) |
| 신뢰 장치 | 리뷰 캡처, 판매량, 테스트, 인증, A/S, 보증 |
| 약점 | 정보가 빠졌거나, 리뷰에서 불만이 나오는데 상세에 답이 없는 것 |

세 개 이상 분석하면 마지막에 **공통 패턴**(셋 다 쓰는 것 = 이 카테고리 필수 요소)과 **빈틈**(아무도 안 하는 것 = 내 차별화 기회)을 따로 정리한다.

### 리뷰에서 뽑을 것
- 별 1~3점 리뷰의 반복 불만 → 공감 섹션과 FAQ 소재, 그리고 내 제품이 정말 해결하는지 확인할 항목
- 별 5점 리뷰의 반복 칭찬 표현 → 고객 언어 그대로 카피에 녹인다(문장을 베끼지는 않는다)
- 상품 문의(Q&A)에서 반복되는 질문 → FAQ

## B. 카테고리 대표 구조

기본 흐름은 템플릿의 15개 섹션이다. 카테고리별로 무게중심을 옮긴다.

| 카테고리 | 앞쪽에 둘 것 | 꼭 넣을 것 |
|---|---|---|
| 주방·생활용품 | 사용 전후 비교, 공감 | 소재 안전(식품용 여부), 세척법, 사이즈 실측 |
| 바·주류 도구 | 연출컷(바 무드), 사용 장면 | 용량(ml/oz), 소재(304 스테인리스 등), 무게감, 세척 |
| 수납·정리 | 정리 전후, 공간별 활용 | 내·외부 치수, 하중, 조립 여부 |
| 패션 잡화 | 착용컷, 컬러 | 실측 사이즈표, 소재 혼용률, 세탁법 |
| 전자·소형가전 | 문제 해결 결과, 스펙 비교 | KC 인증번호, 전원/배터리, 보증 |
| 반려동물 | 아이가 쓰는 장면 | 소재 안전, 크기별 추천 |
| 유아·아동 | 안전, 부모 공감 | KC 인증(어린이제품), 사용 연령 |

## C. 카피 공식

- **히어로**: [대상] + [결과] 또는 [불편] + [해결]. 15자 안팎 두 줄. 예: "흔들 때마다 새던 셰이커, / 이제 한 방울도 안 샙니다".
- **포인트 제목**: 기능이 아니라 결과를 쓴다. "304 스테인리스" → "녹 걱정 없이 매일 씻어 쓰는 304 스테인리스".
- **숫자**: 근거 있는 숫자만. 1688 속성표·실측·직접 테스트에서 나온 값. 없는 숫자는 만들지 않는다.
- **한 섹션 한 메시지**: 섹션 제목만 이어 읽어도 구매 이유가 전달되게 쓴다.
- 문장은 짧게. 모바일에서 한 줄 15~18자 안에 끊긴다고 생각하고 `<br>`로 직접 줄을 나눈다.

## D. 1688 중국어 → 한국어

직역하지 않는다. 한국 쿠팡 고객이 쓰는 말로 바꾼다.

| 1688 표현 | 그대로 옮기면 | 이렇게 쓴다 |
|---|---|---|
| 厂家直销 / 源头工厂 | 공장 직판 | (상세에는 쓰지 않는다) |
| 现货 / 包邮 / 一件代发 | 현물/무료배송/위탁 | (도매 조건이라 쓰지 않는다) |
| 加厚 | 두께 추가 | 더 두툼한 / 두께를 높인 |
| 食品级 | 식품급 | 식품용 등급 소재 (근거 서류가 있을 때만) |
| 304不锈钢 | 304 스테인리스 | 304 스테인리스 스틸 |
| 防滑 | 미끄럼 방지 | 미끄럼 방지 |
| 耐高温 | 고온 내성 | 뜨거운 것에도 강한 (온도 수치가 있으면 함께) |
| 大容量 | 대용량 | 넉넉한 용량 (ml 수치 함께) |
| 简约 / ins风 | 심플 / 인스타 스타일 | 미니멀한 / 감성 있는 |
| 多功能 | 다기능 | 이것 하나로 ~까지 |
| 高颜值 | 높은 외모 | 디자인이 예쁜 / 어디 둬도 예쁜 |
| 爆款 / 热销 | 폭발 상품 / 인기 판매 | (판매 근거 없으면 쓰지 않는다) |
| 规格 / 尺寸 / 重量 / 材质 / 颜色 | 규격/치수/중량/재질/색상 | 옵션 / 사이즈 / 무게 / 소재 / 컬러 |

- 단위: 厘米=cm, 毫米=mm, 克=g, 斤=500g(그램으로 환산), 毫升=ml.
- 이미지 속 중국어 문구도 같은 원칙으로 옮긴다. 과장 문구(第一, 最强 등)는 옮기지 않는다.

## E. 쿠팡 등록 전 점검

**쓰면 안 되는 표현** (근거 서류 없이)
- 최고, 최초, 유일, 1위, 100%, 완벽, 무조건 같은 최상급·단정 표현
- 질병 예방·치료, 살균·항균 효과(시험성적서 없이), "의료용", "인체 무해"
- 실제 진행하지 않는 할인·사은품, 근거 없는 판매량·후기 수
- 타 브랜드명·로고, 연예인 사진, 다른 판매자의 사진·상세 문구

**확인할 것**
- KC 인증 대상(전기용품, 어린이제품, 생활용품 일부)인지. 대상이면 인증번호를 상세와 등록 정보에 넣고, 없으면 등록 전에 사용자에게 알린다.
- 식품 접촉 제품(컵, 도마, 주방도구)은 수입 식품등 신고 대상 여부를 사용자에게 알린다.
- 상품정보제공고시 항목(소재, 크기, 제조국, 제조자/수입자, A/S 연락처)은 쿠팡 Wing 등록 화면에서 따로 입력한다. 상세 하단 스펙표와 값이 같아야 한다.
- 1688 이미지 사용: 공급사 이미지는 보통 재판매용으로 쓰도록 허용하지만, 다른 한국 셀러가 이미 같은 사진을 쓰고 있으면 차별화가 안 된다. 메인 연출컷은 새로 만드는 쪽을 우선한다.
- 생성 이미지는 실제 제품과 색·모양·크기가 달라 보이면 안 된다(반품 사유가 된다).
