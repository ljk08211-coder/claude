# 트랙별 발굴 기준

## 트랙 1. 시즌성 상품

**정의**: 1년 중 4~12주에 판매가 몰리는 상품. 시즌에는 사계절 상품의 3~10배가 팔리지만 시즌이 지나면 재고가 남는다.

**합격 기준**
- 검색량 그래프가 **3년 연속 같은 달에** 솟는다(1년만 솟았으면 유행, 시즌 아님)
- 시즌 피크 검색량이 비시즌의 3배 이상
- 재고 처분 경로가 있다: 다음 해 재판매 가능(부피 작고 변질 없음), 또는 사계절 상품과 묶음 판매 가능
- 입고 마감일 = 시즌 시작일 − 6주. 오늘 기준으로 마감일까지 리드타임이 남아 있어야 한다

**주의**
- 첫 시즌은 **예상 판매량의 60%만** 발주. 남는 것보다 품절이 낫다(품절 시 로켓그로스 노출이 떨어지지만 재고 손실은 더 크다)
- 시즌 상품은 리뷰를 쌓을 시간이 짧다. 시즌 시작 2~3주 전에 판매 개시해서 리뷰를 먼저 확보한다

## 트랙 2. 사계절 상품

**정의**: 월별 검색량 편차가 작고(최고/최저 2배 이내) 소모·교체 주기가 있어 재구매가 나는 상품.

**합격 기준**
- 최근 24개월 검색량 최고/최저 비율 ≤ 2
- 소모품이거나 교체 주기 1년 이내(→ 재구매·리뷰 누적)
- 부피 작고 파손 위험 낮음(로켓그로스 물류비·반품비가 마진을 좌우한다)
- 판매가 1.5만~4만원 구간이 객단가·전환율 균형이 좋다

**찾는 방법**
- 쿠팡 카테고리 베스트에서 "리뷰 수는 많은데 판매자가 여러 명으로 쪼개진" 상품군
- 내가 이미 파는 상품의 **연관 소모품·액세서리**(교체용 부품, 리필, 세척 도구, 보관함)
- 바 운영하면서 매일 쓰는 소모품: 스트로, 코스터, 칵테일 픽, 바 타월, 지거, 붓는 꼭지(푸어러), 병마개, 세척솔

## 트랙 3. 경쟁강도 낮음 + 성장 가능성

**정의**: 검색량은 아직 작지만 꾸준히 오르고, 쿠팡에 제대로 된 판매자가 적은 키워드.

**합격 기준**
- 최근 12개월 검색량이 전년 대비 +30% 이상, 그래프가 계단식으로 오름(한 번 튀고 꺼지는 건 제외)
- 쿠팡 검색 상위 10개 리뷰수 중앙값 300 미만
- 상위 10개 중 평점 4.3 미만이 3개 이상(불만 = 보완 기회)
- 상세페이지 품질이 낮은 상품이 상위에 있다(중국 원본 이미지 그대로, 한국어 설명 빈약)

**아이디어 소스**
- 해외 선행 시장: 아마존·틱톡샵 "Movers & Shakers", 알리익스프레스 급상승 → 국내 쿠팡에 아직 없는 것
- 네이버 데이터랩 쇼핑인사이트에서 카테고리별 급상승 키워드
- 유튜브·인스타 숏폼에서 뜨는 제품(조선바텐더 채널 댓글에서 "그거 어디서 사요?" 질문 나온 도구는 바로 후보)
- 롱테일 키워드: 큰 키워드("얼음틀") 대신 수식어가 붙은 것("위스키 아이스볼 실리콘 4구")

## 공통 탈락 조건

- 인증이 필요한데 공급처가 서류를 못 주는 경우(KC 전기·어린이제품, 식품용 기구·용기 검사, 화장품 등)
- 상표권·디자인권 침해 소지(유명 브랜드 디자인 모방품)
- 부피 대비 단가가 낮아 로켓그로스 물류비가 판매가의 25%를 넘는 경우
- 파손률이 높은 유리 제품은 포장 비용·반품비를 마진 계산에 먼저 넣고 판단
- 상위 3개가 모두 쿠팡 직매입(로켓배송) + 리뷰 1만 이상인 키워드
