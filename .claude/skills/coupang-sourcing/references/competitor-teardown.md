## 해부할 때 보는 포인트

- **썸네일**: 검색 결과에서 3개를 나란히 놓고 봤을 때 내 썸네일이 무엇으로 다르게 보일지(배경색, 사용 장면, 구성 수량 숫자 강조)
- **옵션 구조**: 1위가 옵션을 쪼개서 최저가를 낮게 보이게 하는지(대표 옵션 미끼 가격) 확인
- **단위가격**: 쿠팡은 단위가격을 노출한다. 묶음 구성으로 단위가격에서 이길 수 있는지
- **리뷰 시점**: 최근 3개월 리뷰에서 불만이 늘었으면 공급처가 바뀌었거나 품질이 떨어진 것 → 진입 기회
- **Q&A**: 답변이 없거나 늦은 질문 = 고객이 확신 못 하는 지점 = 상세페이지에서 먼저 답할 것
- **사진 리뷰**: 고객이 실제로 어떤 장면에서 쓰는지가 보인다. 내 상세페이지 사용 장면 컷의 근거
